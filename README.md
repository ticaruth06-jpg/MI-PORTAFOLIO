# Portafolio Académico – Nayeli Quispe Tica

Sitio estático para GitHub Pages. Las tareas se leen **directamente de las carpetas del repositorio**,
así el profesor las ve siempre (ya no dependen de tu navegador).

## Cómo subir una tarea
1. En tu portafolio pulsa **Iniciar Sesión** e ingresa tu clave (en `script.js`, `claveAdministrador`).
2. Entra al curso y, en la semana que quieras, abre **Ver evidencias → ➕ Subir tarea a esta semana**.
3. GitHub abre la página de subida (inicia sesión con tu cuenta). Arrastra tus archivos (PDF, imágenes, ZIP, Word)
   y pulsa **Commit changes**.
4. Espera ~1 minuto y recarga el portafolio: la tarea aparece para todos.

Para **enlaces**: pega el enlace en la semana y pulsa **🔗 Añadir enlace**; GitHub abre con el enlace listo, solo pulsa **Commit new file**.

(Antes: para guardar enlaces manualmente (por ejemplo a otro repositorio), sube a esa misma carpeta un archivo `enlaces.txt`
con un enlace por línea.

## Estructura de carpetas
```
entregas/
├── algoritmo/semana-01/  (tus archivos)
└── taller/semana-01/     (tus archivos)
```
(Se crean solas al subir desde el botón.) Límite de GitHub por archivo desde el navegador: 25 MB.

## Editar el tema de una semana
Inicia sesión, pulsa **✏️ Editar tema**, escribe el nuevo texto y confirma el commit en GitHub (se guarda en `tema.txt` dentro de la carpeta de la semana).
